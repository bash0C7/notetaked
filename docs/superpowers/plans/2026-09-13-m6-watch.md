# M6 Watch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Watch appが前面で録音し、20秒ごとのAAC小片（.m4a）を`WCSession.transferFile`でiPhoneへ送る。iPhoneはWatch由来の小片を専用`Transcriber` streamへ`bufferStartTime`付きで順に流し、`Segment(platform: .watchos, source: .watch, device: <Watch id>)`を`Outbox`→`PeerClient`でMacへ送る。転送完了で小片を削除。

**Spec:** `docs/superpowers/specs/2026-09-12-notetake-design.md`「watchOS」「通信プロトコル > Watch→iPhone」

**環境:** 実装セッションにSwiftツールチェーン無し・実機なし。`NotetakeWatch` targetが`NotetakeCore`に依存するのはこれが初めて（watchOSでCoreがコンパイルできるかはMac側で初めて分かる。`Transcriber.swift`は`#if canImport(Speech)`、`AudioLevel` / `AudioConverter`はAVFoundationなのでwatchOSでもコンパイルできる見込み）。

## Interfaces

Core（純粋）: `Sources/NotetakeCore/Watch/WatchChunk.swift`
```swift
/// WCSession.transferFile の metadata（[String: Any]）と往復する
public struct WatchChunkMetadata: Sendable, Equatable {
    public var session: String        // Watch側の収録id（開始時刻ms文字列）
    public var index: Int             // 0始まり
    public var startAtMS: Int64       // 小片先頭の絶対時刻（Watch時計、epoch ms）
    public var sampleRate: Double
    public var device: String; public var deviceName: String; public var owner: String
    public init(...)
    public init?(metadata: [String: Any]); public var metadata: [String: Any]
}
/// 小片の到着順序を整える（index順、欠番は待つが、あとから届いたindexが小さい小片は捨てずに別streamにはしない: 単純にindex昇順で流し、飛びがあれば飛んだ分の時間だけ bufferStartTime を進める）
public struct WatchChunkSequencer: Sendable { public mutating func accept(_ meta: WatchChunkMetadata) -> [WatchChunkMetadata] /* いま流してよい順 */ }
```

### Watch（`Apps/NotetakeWatch`）
- `WatchRecorder`: `AVAudioSession`（`.record`）、`AVAudioEngine.inputNode` tap → `AVAudioFile(forWriting: url, settings: AAC 16kHz mono 32kbps)`へ書き、20秒ごとにfileを閉じて次へrotate → `WCSession.default.transferFile(url, metadata: meta.metadata)`。`WCSessionDelegate.session(_:didFinish:error:)`でfile削除（errorなら残して次回起動時に再送）
- UI: 開始/停止ボタン、経過時間、未転送小片数。`WKApplication`前面のみ（背景に回ったら停止扱いにせず録音は継続を試みるが保証しない）
- device id: `~/Documents/device-id`にUUID永続、名前は`WKInterfaceDevice.current().name`

### iPhone（`Apps/NotetakeMobile`）
- `WatchRelay`: `WCSessionDelegate.session(_:didReceive file: WCSessionFile)`で`WatchChunkMetadata(metadata:)`→ 小片をアプリのtmpへコピー → `WatchChunkSequencer`で順序整え → Watch sessionごとの`WatchTranscribeStream`（`Transcriber(locale:origin: Date(ms: 先頭小片のstartAtMS))`）へ`AVAudioFile(forReading:)`でPCM読み出し→`AudioConverter`→`feed(buffer, at: sampleTime)`（`sampleTime = (startAtMS - originMS)/1000 * inputFormat.sampleRate`）。final piece → `Segment(platform: .watchos, source: .watch, device: meta.device, owner: meta.owner)` → `Outbox` → `PeerClient`。最後の小片から60秒到着が無ければ`finish()`
