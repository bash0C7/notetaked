# M4 polish（Foundation Models）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `notetaked polish <timed.jsonl>`で、timed.jsonlをReconcilerで統合→話者turn→約2000文字のchunk→Foundation Modelsで「認識誤りの修正・句読点整形・言い淀み除去・意味は変えない・話者ラベル維持」→`<prefix>.polished.md`。失敗chunkは原文採用し末尾に注記。appのメニュー／ライブパネルの「整形」は直近の収録に対して同subcommandを子processで実行する。

**Spec:** `docs/superpowers/specs/2026-09-12-notetake-design.md`「後処理 polish（Foundation Models）」

**環境:** 実装セッションにSwiftツールチェーン無し。Foundation Models APIは一次資料の記憶に基づく（`SystemLanguageModel.default.availability`、`LanguageModelSession(instructions:)`、`respond(to:generating:)`、`@Generable`／`@Guide`、`LanguageModelSession.GenerationError.exceededContextWindowSize`）。Mac側でコンパイルエラーが出たらAPI名を実SDKに合わせて直す（HANDOFF参照）。

## Interfaces

Core（純粋、実装済み: `Sources/NotetakeCore/Polish/`）: `PolishTurn` / `PolishChunk` / `PolishedTurn` / `PolishChunker.turns(from:)` / `.chunks(_:maxCharacters:contextTurns:)` / `.merge(outputs:chunks:)` / `PolishRenderer.markdown(_:timeZone:)`

daemon `Sources/notetaked/Polish/Polisher.swift`（`#if canImport(FoundationModels)`）:
```swift
@available(macOS 26, *)
enum Polisher {
    @Generable struct PolishedTurnOutput { @Guide(description: "話者ラベル。入力のまま") var speaker: String; @Guide(description: "整形後の本文") var text: String }
    @Generable struct PolishedChunkOutput { var turns: [PolishedTurnOutput] }
    static func availabilityError() -> String?      // SystemLanguageModel.default.availability が .available でなければ理由文字列
    static func polish(chunk: PolishChunk) async -> [(speaker: String, text: String)]?   // chunkごとに新しいLanguageModelSession(instructions:)。context turnは「文脈（出力しない）」として、body turnは番号付きで渡し、body件数と同数のturnsを返すよう指示。失敗（GenerationError / その他）はnil
}
```
`Sources/notetaked/Commands/PolishCommand.swift`: `polish <timed.jsonl> [--output <path>]`。Render commandと同じくtimed.jsonlをdecodeAll→`Reconciler.fold`→`PolishChunker.turns`→chunks→順にPolisher.polish（chunk間は直列）→merge→`PolishRenderer.markdown`→`<prefix>.polished.md`（`--output`指定時はそこへ）。stderrに進捗（`chunk i/N`）。可用性なしは非0 exitでメッセージ。

app: `AppModel.lastFinishedPrefix: String?`（停止／区切りで直前の収録prefixを記憶。`status(recording:false)`受信時は直前の`prefix`、rotateの`status`受信時は旧prefix）。`func polishLastRecording()`: `Process`で`notetaked polish <outputDirectory>/<prefix>.timed.jsonl`を実行（bundle内の`notetaked`）、完了で`lastLog = "整形完了: <prefix>.polished.md"`または`lastError`。`isPolishing`で多重起動防止。メニュー「直前の収録を整形」・ライブパネル「整形」（`lastFinishedPrefix == nil || isPolishing`で無効）。
