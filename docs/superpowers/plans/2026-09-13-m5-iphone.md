# M5 iPhone Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** iPhone appがマイクをSpeechAnalyzerで文字起こしし、segを`Outbox`に溜めつつBonjour/TLS(PSK)でMacのdaemonへ送る。Macは`(device, seq)`で冪等に受け取り、`clock_offset_ms`を付けて該当収録のtimed.jsonlへ追記（停止後に届いた分はfinal.mdを再生成、どの収録にも入らなければ`orphans.jsonl`）。Reconcilerがデバイス横断で統合する。

**Spec:** `docs/superpowers/specs/2026-09-12-notetake-design.md`「通信プロトコル（iPhone→Mac）」「Mac daemonの詳細 > 収録外の受信」

**環境:** 実装セッションにSwiftツールチェーン無し・実機なし。Network frameworkのTLS PSK設定（`sec_protocol_options_add_pre_shared_key`・`sec_protocol_options_append_tls_ciphersuite`）は一次資料の記憶に基づく。**Apple Development証明書の再発行が実機ビルドの前提**（HANDOFF）。

## Interfaces

Core（純粋、実装済み: `Sources/NotetakeCore/Peer/`）: `PeerMessage`（hello / hello_ack / ping / pong / seg / ack）、`ClockOffset`、`SessionMatcher` / `SessionSpan`、`Outbox`

### daemon
- `Sources/notetaked/Peer/PeerListener.swift`（actor）: `init(pairingCode: String, port: UInt16 = 0, onMessage: ...)`。`NWListener(using: params)`、`params.includePeerToPeer = true`、`listener.service = NWListener.Service(name: "<Mac名>", type: "_notetake._tcp")`。TLS: `NWProtocolTLS.Options()`に`sec_protocol_options_add_pre_shared_key(options.securityProtocolOptions, psk: DispatchData(code utf8), psk_identity: DispatchData("notetake"))`、`sec_protocol_options_append_tls_ciphersuite(..., tls_ciphersuite_t(rawValue: UInt16(TLS_PSK_WITH_AES_128_GCM_SHA256))!)`、`sec_protocol_options_set_min_tls_protocol_version(..., .TLSv12)`。接続ごとに`PeerConnection`（NDJSON行の受信: `receive(minimumIncompleteLength:1, maximumLength: 65536)`を繰り返し`\n`で分割。送信は`send(content:completion:)`）。`hello`→`hello_ack`、以後 Macから`ping`を接続直後に5回・以後60秒ごとに送り`pong`で`ClockOffset.best`、`seg`→`ack`
- `ServeSession`に`handlePeer(_ message: PeerMessage, from connection: PeerConnectionID)`: `hello`で`DeviceRecord(offset_ms: 現在の推定)`をtimed.jsonl（進行中なら）に書く。`seg`: `(device, seq)`の既受信集合で冪等（`~/Library/Application Support/Notetake/received/<device>.cursor`に最大seqを保存）、`clockOffsetMS = ClockOffset.segmentOffsetMS`、`receivedAt`付与、`SessionMatcher.match`で収録を選ぶ: 進行中→store.append + reconciler + utteranceイベント。過去→その`timed.jsonl`に追記して`Reconciler.fold`→`final.md`再生成（`log`イベント）。無し→`<output>/orphans.jsonl`へ追記。いずれも`ack`
- `Command.pairCode(String)`（`{"cmd":"pair_code","code":"123456"}`）: appが起動時に生成して送る。daemonはlistenerを（再）起動。`--pair-code`引数でもCLI単体起動できる。`Event.peer(device:deviceName:connected:Bool)`をappへ
- `serve`起動時に過去収録の`SessionSpan`一覧を出力ディレクトリの`*.timed.jsonl`の`session`行と最終segから作る（`SessionIndex`）

### app（Mac）
- 設定Windowに6桁ペアリングコード表示（UserDefaults `pairingCode`、初回生成、「再生成」ボタン）。daemon起動後に`pair_code`を送る。ライブパネル状態行に接続デバイス名

### iOS app（`Apps/NotetakeMobile`）
- `PeerClient`（actor）: `NWBrowser(for: .bonjour(type: "_notetake._tcp", domain: nil), using: params)`で発見→`NWConnection(to: endpoint, using: paramsWithPSK)`→`hello`→未ack segをseq順に再送→`ack`で`Outbox.acknowledge`。切断時はbackoff再接続
- `Recorder`: `AVAudioSession`（`.playAndRecord`／`.record`、`allowBluetooth`）+ `AVAudioEngine.inputNode` tap → `AudioConverter` → `Transcriber`（NotetakeCore）→ final → `Segment(platform: .ios, source: .mic, device: <UUID永続>, owner: 設定名)` → `Outbox.append` → `PeerClient.enqueue`
- UI: 開始/停止、接続状態（未接続／Mac名）、outbox残数、ペアリングコード入力（Keychainに保存）、自分の名前
- Info.plist（project.yml済み）: NSLocalNetworkUsageDescription / NSBonjourServices / UIBackgroundModes audio
